## About

I build the infrastructure that makes AI systems trustworthy — retrieval architectures you can trace, agent protocols that scale, and knowledge systems that don't hide behind a black box. My work sits at the intersection of systems design and applied AI: less about chasing benchmarks, more about building things that hold up in production.

---

## What I've Learned Building These

- **Retrieval doesn't need to be a black box.** Graph and keyword-based traversal can answer the same questions as vector search, and you can read every step of how it got there.

- **Most model-to-tool glue gets written twice.** Standardising on a protocol layer (MCP) removes the custom integration work that piles up as a system grows.

- **Grounding is a pipeline problem, not a prompt problem.** Hallucination rates move when you fix retrieval and context assembly, not when you rewrite the instruction.

- **Documentation structure is retrieval structure.** How you chunk and link your source material decides the ceiling on answer quality before the model is ever involved.

- **Local-first is a real deployment target.** Running models on-device changes what you can promise about latency, cost, and where the data goes.
